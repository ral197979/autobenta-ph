## The Daily 90-Minute Routine

Run this block every weekday. Total time: 90 minutes. Do it before your inbox, before Slack, before anything else.

**9:00–9:15am — Morning Review (15 min)**
Open `/admin/growth`. Answer these four questions before moving on:
1. Did any demo bookings come in overnight via `/book-demo`?
2. Which prospects in `/admin/founding-dealers` have a follow-up due today?
3. What is the current paying dealer count? MRR?
4. Is anyone in "Proposal Sent" stage who hasn't responded in 48+ hours? (Call them today.)

Set a sticky note or phone reminder for anyone who needs action today. Then move to outreach.

**9:15–9:45am — Outreach Block (30 min)**
Open `sales/TARGET_DEALERS.csv`. Open `sales/templates/`. Do all of these in sequence:
- Contact 10 prospects. Start with HIGH priority rows. Work down.
- Use the correct template for each stage:
  - First ever contact → `COLD_OUTREACH_EMAIL` or `COLD_OUTREACH_WHATSAPP`
  - Contacted once, no reply → `FOLLOW_UP_1` (send Day+2 after first contact)
  - Contacted twice, no reply → `FOLLOW_UP_2` (send Day+4 after first contact, switch channel)
  - Attended demo → `POST_DEMO_FOLLOWUP` (send within 24 hours of demo)
  - Sent proposal → `PROPOSAL_FOLLOWUP` (send 48 hours after proposal)
- Personalize every message: dealer name, city, specific inventory type (e.g., "Japanese imports", "pickup trucks"). Generic blasts do not close deals.
- If a prospect has a Facebook Marketplace page, reference one of their listings by name.

**9:45–10:15am — Demo Calls or Follow-Up Calls (30 min)**
- Run any scheduled demo calls from your calendar (booked via `/book-demo`).
- Make follow-up calls to warm prospects (anyone in "Demo Scheduled", "Demo Completed", or "Proposal Sent" stage).
- Rule: if you have sent 2 messages with no reply, your next contact is a phone call. Not a third message.
- Have `DEMO_BOOKING_PROCESS.md` open during demos. Use `COMPETITOR_BATTLECARDS.md` if objections come up.

**10:15–10:30am — Log and Plan Tomorrow (15 min)**
Open `/admin/founding-dealers`. For every contact made today:
- Move the prospect card to the correct Kanban stage.
- Log the contact attempt in the card notes (channel used, what was said, response).
- Set the next follow-up date on the card. No card should ever have a blank next-follow-up date.
- Open calendar. Block the follow-up slots for tomorrow.

Done. Close the laptop. Do not check sales stuff again until the next morning block.

## The 10 Non-Negotiable Rules

These are not suggestions. If you break them, you create work for yourself later.

1. **Every contact attempt is logged in CRM. No exceptions.** If it's not in `/admin/founding-dealers`, it didn't happen. This protects you from duplicate outreach and lost deals.

2. **Every follow-up gets a next-follow-up date set. No dead ends.** A prospect with no follow-up date set is a prospect you will forget. Every card must have a date.

3. **Every demo gets a post-demo email within 24 hours.** Use `POST_DEMO_FOLLOWUP` template. Personalize it with one specific thing the dealer said during the demo. Send it same day if possible.

4. **Never discount below ₱2,999/mo. The floor is the floor.** If a dealer pushes on price, offer a shorter contract or a free trial week — not a lower number. Discounting signals that ₱3,599 was not the real price.

5. **When in doubt, call. Not message.** Messages are easy to ignore. Calls are harder to ignore and close more deals. If you've sent 2 messages, the next contact is a phone call.

6. **No new feature development until Dealer #5 is paying.** If you build something new, you are not doing sales. Features do not close deals. Calls close deals.

7. **Every "not now" gets a 30-day re-engage calendar entry.** "Not now" is not "no." Set a calendar reminder for 30 days out. Add a note: what was their hesitation? What changed at that time might make them say yes.

8. **Collect one piece of product feedback from every demo.** Ask: "What would make this a no-brainer for you?" Write the exact answer word-for-word in the CRM card. This feeds the postmortem.

9. **Send NPS survey at Day 14 for every onboarded dealer.** Don't wait for them to complain. Ask before they have a reason to. Use the NPS survey in `CUSTOMER_SUCCESS_PLAYBOOK.md`.

10. **Review `/admin/growth` every single morning before outreach.** You cannot optimize what you don't see. The dashboard tells you where you are. If you skip it, you will outreach the wrong people.

## Decision Tree — What To Do If Stuck

Use this when the sprint is off track. Be honest with yourself about which branch applies.

**Problem: No one is responding to outreach**
→ First: are you sending enough? 10/day minimum. If yes:
→ Switch channel. If email → try WhatsApp. If WhatsApp → try phone call.
→ If phone calls get no answer: change message angle. Try: "I saw your [listing] on Facebook Marketplace" (specific). Delete the generic opener.
→ If 3 channel switches still nothing: the prospect is cold. Move to next prospect. Return in 30 days.

**Problem: Getting demos but no closes**
→ Re-read `DEALER_OBJECTION_HANDLING.md`. Match each stall to a response.
→ Are you showing the ROI calculator? Price objections melt when you show ₱ recovered per month in leads.
→ Are you asking for the close directly? At end of demo say: "Does this make sense for your business? Can we get you started today?"
→ If demos are enthusiastic but still no close: add urgency — "We have [X] founding spots remaining this week."

**Problem: Closing but dealers are churning**
→ Drop outreach. Call the churning dealer immediately. Do not send a message. Call.
→ Open `CUSTOMER_SUCCESS_PLAYBOOK.md`. Follow the churn prevention protocol.
→ Root cause: is it onboarding failure (dealer didn't get value in first 14 days)? Or product gap? Or expectation mismatch from demo?
→ Fix the root cause before closing the next dealer.

**Problem: Demo no-shows above 50%**
→ Send a WhatsApp confirmation message 1 hour before every demo (not just an email).
→ Shorten the demo ask. Instead of "30-minute demo," offer "15-minute quick look — I'll show you one thing that'll make your inventory move faster."
→ Offer a self-guided option: record a 10-minute Loom of the platform, send it with a follow-up call booked.

**Problem: Running out of prospects in the CSV**
→ Mine Facebook Marketplace PH groups (search "used car dealer [city]").
→ Check Carousell PH for dealers with 10+ listings (they are professional sellers, not individuals).
→ Ask every won dealer for one referral ("Do you know another dealer who'd benefit from this?").
→ OLX Philippines: filter by cars, sort by most listings per seller.

## When To Deviate From This Plan

Only three situations justify breaking the daily routine:

**1. A dealer is about to churn.**
Drop everything. Call them now. A churning Founding Dealer is a catastrophic signal — they are your social proof. Fix the problem before you do anything else today. Log what happened. Adjust onboarding if needed.

**2. A revenue-blocking bug is reported.**
A bug that prevents a dealer from logging in, listing a car, or receiving a lead is a revenue-blocking bug. Fix it within 4 hours (your SLA commitment). Log it. Then return to the sales routine.

**3. A dealer requests a specific integration.**
Do not build it. Say: "That's a great idea — I'm tracking feature requests and will prioritize based on dealer demand. If two more dealers ask for the same thing, I'll build it in the next sprint." Create a DealerFeedback record. That's it.

Everything else — competing priorities, admin tasks, redesign ideas, optimization opportunities — waits until Day 31.
